# Obstacle-Avoidance Robot Car

Autonomous obstacle-avoidance robot car built with an Arduino Uno, an HC-SR04 ultrasonic sensor, and an L298N motor driver. The car drives at full speed when the path is clear, slows down with an intermittent alert when an obstacle is within 20 cm, and stops completely with a solid alert when an obstacle is within 10 cm.

## Contents

- **`Obstacle Avoidance Robot Car.pdf`** — Full write-up covering the design, circuit, code, testing, and results.
- **`Obstacle Avoidant Robot Car.ino`** — Arduino sketch that runs the robot.

## Built With

- Arduino Uno
- HC-SR04 ultrasonic distance sensor
- L298N motor driver
- DC motors, LEDs, and a piezoelectric buzzer
